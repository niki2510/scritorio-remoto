# Contribuir

Gracias por mejorar Escritorio Remoto Bravo.

1. Crea un *fork* y una rama desde `main`.
2. Instala las dependencias con `pip install -r requirements.txt` y `pip install pytest`.
3. Mantén los cambios pequeños y añade pruebas cuando cambie el comportamiento.
4. Ejecuta `pytest -q` antes de abrir el *pull request*.
5. No incluyas credenciales, configuraciones de `instance/`, dominios privados ni artefactos compilados.

Describe en el *pull request* el problema, la solución y cómo se verificó.
