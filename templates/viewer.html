GUÍA DEL USUARIO

Cómo usar Escritorio Remoto

Controla otro equipo, intercambia archivos y conecta dispositivos desde una sola interfaz.

Primeros pasos
EmpezarEscritorio ArchivosDispositivos Acceso remotoSeguridad Problemas frecuentes

1. Primeros pasos

  1. Inicia el servidorEjecuta run.sh en Linux o run.bat en Windows en el equipo que vas a controlar.
  2. Abre la direcciónDesde otro dispositivo entra en http://IP-DEL-EQUIPO:5000, o usa el dominio configurado.
  3. Inicia sesiónUsa las credenciales mostradas en el primer arranque. Puedes cambiarlas en Configuración.
  4. Controla el equipoEn Escritorio Web, haz clic sobre la imagen para activar teclado y ratón.
El equipo remoto debe estar encendido, conectado a la red y con una sesión gráfica activa. En Linux se recomienda X11/Xorg.

Escritorio Web

  • Mueve y pulsa el ratón directamente sobre la imagen.
  • Haz clic en el escritorio antes de escribir con el teclado.
  • Usa «Enviar» para pegar textos completos.
  • El botón ⛶ activa la pantalla completa.
  • Ajusta calidad y FPS en Configuración.

Archivos y FTP

  • En FTP, el panel izquierdo es tu dispositivo y el derecho el servidor remoto.
  • Selecciona archivos o una carpeta y usa «Subir todo →».
  • Para descargar, selecciona un agente local o usa la acción del archivo.
  • Configuración permite crear, borrar, subir y descargar carpetas.

Consejo: el navegador necesita que selecciones la carpeta local por seguridad.

Dispositivos conectados

Consulta navegadores y agentes conectados, asigna tu nombre y abre un chat privado. El agente local añade datos reales de red y permite recibir transferencias.

La propia pestaña ofrece instaladores para Linux y Windows. Instálalo solo en equipos de confianza.

Acceder desde fuera

Se recomienda una VPN o Cloudflare Tunnel con HTTPS. Redirigir un puerto del router expone el servicio a Internet y exige más protección.

Configura el dominio y el túnel en Configuración. Si cambias de red, comprueba que servidor y túnel siguen activos.

Uso seguro

  • Cambia la contraseña inicial y no la reutilices.
  • Prefiere HTTPS, VPN o un túnel autenticado.
  • No compartas tokens, contraseñas FTP ni archivos de instance/.
  • Limita la carpeta publicada por el gestor.
  • Cierra sesión en equipos compartidos.
  • Mantén dependencias y sistema actualizados.

Problemas frecuentes

La pantalla aparece negra o no se actualiza

Comprueba que hay una sesión gráfica activa. En Linux usa Xorg/X11; Wayland restringe captura y control.

El teclado o el ratón no responden

Haz clic sobre el escritorio para darle foco. En Windows, UAC y la pantalla de inicio pueden bloquear la entrada por diseño.

No puedo conectar desde otro equipo

Verifica red, puerto 5000 y que firewall, VPN, proxy o túnel permiten HTTP y WebSocket.

La conexión va lenta

Reduce FPS, calidad JPEG y ancho máximo en Configuración. Una red por cable suele ser más estable.

No puedo mover archivos

Revisa permisos, espacio libre y tamaño. Para acceder al disco del cliente instala y selecciona el agente local.

Transmisión de pantalla

Se aplican al instante, sin reiniciar el servidor.

Credenciales de acceso

Servidor FTP del equipo remoto

Este equipo es siempre el servidor/origen. Los clientes son el navegador web y la aplicación Windows conectados a él.

Entre redes distintas deben permitirse TCP 2121 y el rango pasivo TCP 30000–30049 hacia este servidor.

Acceso directo por IP pública y router

Alternativa a Cloudflare Tunnel. Configura en el router una redirección TCP desde la IP y puerto públicos hacia la IP local de este servidor.

⚠️ Este modo expone el servicio directamente a Internet. Usa una contraseña robusta y HTTPS siempre que sea posible.

Exponer con subdominio (Cloudflare Tunnel)

⚠️ Antes de generar un subdominio para acceder a este equipo desde otra ubicación, asegúrate de que esta aplicación esté instalada y en ejecución en el equipo que quieres controlar de forma remota. ¿Aún no la tienes instalada allí? Descargar aplicación (.zip)

Funciona para cualquier dominio registrado en tu cuenta de Cloudflare (.com, .es, .net...). Requiere tener cloudflared ya autenticado en este equipo y un túnel existente (ver opciones avanzadas).
